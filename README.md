## Hur man kör programmet

### Det här behövs
- Visual Studio (eller annan C#-editor)
- .NET SDK (version: ___)

### Steg för steg
1. Klona repot: `git clone https://github.com/Fariskaraduz/JobApplicationTracker.git`
2. Öppna lösningsfilen (`.sln`) i Visual Studio.
3. Tryck på **F5** (kör med felsökning) eller **Ctrl+F5** (kör utan).
4. Konsolfönstret öppnas och menyn visas.

### Så använder du programmet
1. Skriv ett nummer (1-8) i menyn och tryck Enter.
2. Följ instruktionerna på skärmen. Datum skrivs som `yyyy-MM-dd`, till exempel `2026-10-19`.
3. Välj 8 för att avsluta.

### Menyval
| Nr | Funktion |
|----|----------|
| 1 | Lägg till ny ansökan |
| 2 | Visa alla ansökningar |
| 3 | Filtrera efter status |
| 4 | Sortera efter datum |
| 5 | Visa statistik |
| 6 | Uppdatera status |
| 7 | Ta bort en ansökan |
| 8 | Avsluta |

### Tips
- Data sparas inte när programmet stängs, den finns bara i minnet medan det körs.
